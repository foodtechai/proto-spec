# PROTO·SPEC

프롬프트에 원하는 서비스를 입력하면 **클릭 가능한 프로토타입**을 만들고, **화면설계서**로 정리한 뒤 **품질 QA**로 검사하는 팀 공용 화면입니다.

팀 주소는 https://foodtechai.github.io/proto-spec/ 입니다. 상단의 **프로토타입**, **화면설계서**, **품질 QA**를 눌러 단계를 이동합니다.

1. 만들고 싶은 서비스를 입력한 뒤 **프로토타입 만들기**.
2. 만들어진 화면의 **이 화면 수정**에 내용을 적으면 그 프로토타입만 고칩니다.
3. **다시 입력**으로 처음 화면에 돌아가 프롬프트를 적으면, 기존 화면을 이어서 고치지 않고 새 프로토타입을 만듭니다.
4. 폰 화면을 눌러 흐름을 확인합니다.
5. **화면설계서**에서 정보구조, 사용자 흐름, 화면 정의, 컴포넌트 명세를 확인합니다.
6. **품질 QA**에서 이동 경로, 요구사항 반영, 정책, 접근성을 항목별로 검사합니다.

각자 브라우저에 마지막 작업이 저장됩니다. 같은 컴퓨터를 쓰지 않으면 서로 화면이 섞이지 않습니다.

같은 품질 규칙을 터미널에서 확인하려면 `node test.js`를 실행합니다.
