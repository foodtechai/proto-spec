# PROTO·SPEC

프롬프트에 원하는 서비스를 입력하면 **클릭 가능한 프로토타입**을 만들고, **화면설계서**로 정리한 뒤 **품질 QA**로 검사하는 로컬 웹 도구입니다.

1. `node server.js`를 실행하고 브라우저에서 `http://127.0.0.1:8765/` 를 엽니다.
2. 만들고 싶은 서비스를 입력한 뒤 **프로토타입 만들기**.
3. 자유롭게 고치려면 [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 Gemini 키를 만들고, 화면의 **연결**에 붙여 넣습니다. 키는 이 컴퓨터의 `.env`에만 저장됩니다.
4. 만들어진 화면의 **이 화면 수정**에 내용을 적으면 그 프로토타입만 고칩니다. 키가 있으면 Gemini가 문장을 해석하고, 없으면 제목·화면 추가 같은 기본 규칙만 적용됩니다.
5. **다시 입력**으로 처음 화면에 돌아가 프롬프트를 적으면, 기존 화면을 이어서 고치지 않고 새 프로토타입을 만듭니다.
6. 폰 화면을 눌러 흐름을 확인합니다.
7. **화면설계서 작성**으로 정보구조, 사용자 흐름, 화면 정의, 컴포넌트 명세를 확인합니다.
8. 화면설계서에서 **품질 QA**를 누르면 이동 경로, 요구사항 반영, 정책, 접근성을 항목별로 검사합니다.

설치 프로그램이 필요 없습니다. 마지막 작업은 브라우저에 저장됩니다.

같은 품질 규칙을 터미널에서 확인하려면 `node test.js`를 실행합니다.
